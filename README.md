# 🏋️‍♂️ KineLab Academy® – Formación Deportiva Profesional

Este proyecto corresponde a la **Entrega Final del curso de React JS**.  
Consiste en una **Single Page Application (SPA)** de **e-commerce** educativa dedicada a la formación deportiva y entrenamiento basado en evidencia.

La plataforma permite visualizar cursos disponibles, acceder a su detalle, agregarlos al carrito y finalizar una compra registrando la orden en una base de datos remota.

---

## 🚀 Tecnologías utilizadas

- **React JS**
- **Vite**
- **React Router DOM**
- **Context API**
- **Firebase / Firestore**
- **HTML5 / CSS3**
- **JavaScript ES6**

---

## 🧠 Funcionalidades principales

| Funcionalidad | Detalle |
|--------------|---------|
| SPA sin recargas | Navegación con React Router |
| Listado dinámico de productos | Consulta a Firebase |
| Vista de detalle del producto | `/item/:id` |
| Filtrado por categorías | `/category/cursos` y `/category/ebook` |
| Carrito de compras global | Context API |
| Contador de unidades | `ItemCount` con validación de stock |
| Checkout de compra | Registro de orden en Firestore |
| Renderizado condicional | Loader, carrito vacío, sin stock, etc. |
| ID de orden final | Se muestra al usuario al finalizar la compra |
